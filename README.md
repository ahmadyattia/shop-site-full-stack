Shop Site E-commerce Platform

It is a full-stack project intended for practice and as an evidence of my web development abilities. You can sign up, log in, view products according to their category, add them to your cart both while logged in or logged out, place an order, and view your orders while logged into your account.

Across this project, I've implemented data validation, loading and error states, pagination, breadcrumbs, SPA frontend architecture, CSS Modules, global and local state, environment variables, typing using TS, auth cookies, Json Web Tokens, handling response status codes, and more. 

Frontend Tech Stack:
- React.js in TypeScript: Frontend framework
- React Router: Client-side routing API provided by React
- React Context: State management API provided by React
- Axios: HTTP client library

Backend Tech Stack:
- Node.js in TypeScript: Backend runtime
- Express: HTTP server framework

Database:
- PostgreSQL: RDBMS (Relational Database Management System)
- SQL: Database query language
