Full-stack e-commerce website for showcasing my skills as a web developer.

Frontend URL: shop-site-with-backend-three.vercel.app (Deployed on Vercel)
Backend URL: https://shop-site-with-backend.onrender.com/ (Deployed on Render)

Render spins down the server after a period of inactivity. It can take up to 50 secs to spin up again.
